# 👑 THE ROAD TO DOOM — Ultimate MCU & Multiverse Preparation Guide

A modern, highly immersive web application and watch tracker built for Marvel fans preparing for **Avengers: Doomsday** (December 18, 2026) and **Avengers: Secret Wars**.

Inspired by [theroadtodoom.com](https://www.theroadtodoom.com/), but streamlined, upgraded, and enhanced with curated storylines, audio synthesizers, holographic ticket stubs, and in-depth comic book research.

---

## ⚡ Key Highlights & Improvements

### 1. 🎯 Streamlined, Filler-Free Watchlist
- **All MCU Movies Included**: Complete cinematic journey from *Iron Man (2008)* through Phase 6 (*Captain America: Brave New World*, *Thunderbolts\**, *The Fantastic Four: First Steps*, *Spider-Man 4*, up to *Avengers: Doomsday*).
- **Essential Series Only**: Unlike bloated trackers listing 30+ shows (e.g. *She-Hulk*, *Secret Invasion*, *Echo*), this guide filters down exclusively to the **narratively mandatory series**:
  - **Loki (Seasons 1 & 2)** — TVA, Sacred Timeline, Multiversal Loom, and God of Stories Loki holding Yggdrasil together.
  - **WandaVision** — Scarlet Witch Nexus Being awakening, Darkhold introduction, setting up Incursions & Wiccan.
  - **The Falcon and the Winter Soldier** — Sam Wilson taking up the Captain America mantle, Bucky Barnes, US Agent, and Valentina's Thunderbolts setup.
  - **What If...? (Season 1)** — The Watcher, Strange Supreme, and universal collapse mechanics.
  - **Agatha All Along** — Billy Maximoff (Wiccan) and astral realm mystic rules.
- **Multiverse & Mutants Support**: Curated Fox *X-Men* classics (*X-Men*, *X2*, *Days of Future Past*, *Logan*, *Deadpool & Wolverine*) and Sony *Spider-Man* legacy films.

### 2. 🔥 Fast Track Short Road (10 Pure Milestones)
- The absolute direct storyline milestones to understand Doctor Doom, the Multiverse collapse, and the Battleworld incursion crisis without any filler.

### 3. ⏳ Live Countdown HUD
- Precise real-time countdown to **December 18, 2026** (*Avengers: Doomsday*).
- Live watch time calculator displaying total remaining runtime vs hours watched.

### 4. 🎟️ Holographic Stub Wall & Collectible Generator
- Collectible holographic Marvel movie ticket stubs generated automatically for watched films.
- Rate titles (1 to 5 stars), write personal reviews, and export/print your scorecard.

### 5. 🏆 Achievement Badges & Secrets
- 14+ unlockable achievement badges for Phase completions, the Infinity Saga, the Short Road, and secret Easter eggs (click the Doom Mask 5 times to unlock *Kneel Before Doom*).

### 6. 🔊 Latverian Audio Synthesizer (Web Audio API)
- Zero external audio files required! Built with native browser oscillators for responsive SFX, achievement fanfares, and toggleable cosmic ambient drones.

### 7. 📜 Secret Wars & Incursion Lore
- Deep dive into Jim Shooter's *Secret Wars (1984)* and Jonathan Hickman's *Secret Wars (2015)*, God Emperor Doom, the Molecule Man, the Beyonders, and how Incursions function in the MCU.

## 🚀 How to Run

No build step or Node.js installation required!

### Option 1: Direct Browser Launch
Simply double-click `index.html` in file explorer or open it directly in Chrome, Edge, Firefox, or Safari:
```
C:\Users\SarthakIG\Documents\ROADTODOOM\index.html
```

### Option 2: Local Python Web Server
Open PowerShell in this directory and run:
```powershell
python -m http.server 8000
```
Then visit: `http://localhost:8000`
